# Penguin Fashion

A modern and responsive fashion e-commerce landing page built using Tailwind CSS. This project focuses on clean UI design, mobile-first responsiveness, and reusable components.

Live Site: https://penguin-fashion375.netlify.app/  
GitHub Repo: https://github.com/MdBelayet3/penguin-fashion-tailwind  

---

## Features

- Fully responsive design (Mobile, Tablet, Desktop)
- Clean and modern UI
- Product showcase section
- Men's and Women's fashion categories
- Fast performance with Tailwind CSS
- Mobile-first approach

---

## Technologies Used

- HTML5
- Tailwind CSS
- CSS3

## Getting Started

To run this project locally:

```bash
git clone https://github.com/MdBelayet3/penguin-fashion-tailwind.git
cd penguin-fashion-tailwind
```

Then open `index.html` in your browser.
